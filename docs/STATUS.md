# 开发状态与后续计划

更新：2026-10-19。当前为 Windows 本地基础用户测试版本。

## 已完成

- 本地工作台、独立浏览器窗口、可双击图标与快捷方式生成器。
- SiliconFlow / OpenAI 切换，统一左侧配置、模型搜索、自定义和截图价格。
- 按指定预置 XingChen 语音模型与两个聊天模型，仅保存模型选择。
- 音视频上传、标准化和分段；时间范围、处理覆盖、异常标记和音频定位。
- 编辑、预览、复制、原文恢复、问答和会议纪要提示。
- Markdown / Word 固定目录保存、路径提示与防重名覆盖。
- 运行故障排查、合成音频与文件写入验证、使用和开发文档。

## 已排查

1. 受限进程 EACCES：正常权限重启后官方接口可达，新增明确错误提示。
2. 提示下载却找不到：旧页面未显示路径和原文件名，实际已保存通用名称；核对真实文件并增加完整路径提示。
3. 无法判断处理到结尾：增加实际分段时间和异常状态，仍需人工听检是否漏字。

## 验证阶段

自动化与合成音频界面测试通过，用户使用中已产生真实时间戳文稿和导出文件。这不代表全部模型均完成真实调用验证，也不等于系统准确率评估。

用户测试建议记录：录音长度、噪声、模型、间隔、段数、空结果、遗漏、专业词汇、耗时与导出结果。对比服务商时使用同一录音，避免把总结质量当作转写准确率。
